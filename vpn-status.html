Not connected — no VPN server configured

Cloudflare Pages/Workers can host this control page, but cannot give this project an exclusive public IP or a native IKEv2/WireGuard device-wide VPN server. GitHub Codespaces TCP forwarded ports are not a dependable native VPN endpoint.

Turning on a website switch would not change the IP address of Windows or Android. No simulated ON button is provided.

Requirements before activation

  1. A reachable VPN server outside your country with a public endpoint.
  2. An exclusively assigned public IP for static dedicated mode; multiple exclusive IPs for rotation.
  3. Compatible encrypted VPN protocol and secure per-device credentials.
  4. Windows and Android client compatibility verified on actual devices.
  5. IP, DNS-leak, routing and speed tests after deployment.

Free, no-card hosting with dedicated international IP is not currently verified. Do not deploy secrets to public Pages JavaScript or commit credentials to GitHub.
